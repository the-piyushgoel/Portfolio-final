# 🌐 Personal Portfolio

A modern and responsive personal portfolio built with **React** and **CSS**, showcasing my skills, education, career journey, and contact information. The project is designed to provide a clean and engaging user experience while maintaining a fast and lightweight architecture.

## ✨ Features

- 🎨 Clean and responsive UI
- ⚛️ Built with React
- 📱 Mobile-friendly design
- ⌨️ Dynamic typing animation
- 📄 Resume download functionality
- 📚 Dedicated sections for Skills, Education, Career, and Contact
- 📧 Contact form integration
- 🌐 Social media links
- ⚡ Fast and optimized performance

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/the-piyushgoel/Portfolio.git
```

Navigate into the project

```bash
cd Portfolio
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview the production build

```bash
npm run preview
```
